# 猫咪科普网站 · ChatGPT 提示词

> 用途：将下面代码框内的整段内容复制给 ChatGPT，让它生成一个「猫咪物种科普 + 品种图鉴」单页网站。

```text
# 角色
你是一位猫科动物科普作者兼资深前端工程师。请为我制作一个「猫咪科普与品种图鉴」单页网站,所有文案使用简体中文,语气轻松有趣、信息准确。

# 一、页面结构(自上而下)

## 1. 顶部导航
吸顶导航,含网站名(可自拟,例如"喵星球百科")与锚点链接:首页 / 猫咪科普 / 品种图鉴 / 趣味冷知识。移动端折叠为汉堡菜单。

## 2. Hero 首屏
- 主标题 + 副标题(例如:"从一只猫开始,认识整个喵星球"),一句话说明网站内容:猫咪物种科普 + 品种图鉴
- 一个主按钮,平滑滚动到科普区
- 背景为暖色柔和渐变,配大号猫咪 emoji 或内联 SVG 剪影装饰

## 3. 「猫是什么」科普区
以信息卡片或时间线呈现,每块 60~120 字:
- 分类学:猫科猫属小型动物,学名 Felis catus,和老虎、狮子同属猫科
- 驯化史:约 1 万年前近东地区,非洲野猫因守护谷仓与人类结缘,是"自我驯化"的捕鼠伙伴
- 超强感官:听力上限约 64kHz、夜视能力约为人类 6 倍、胡须是精密的"空间探测器"
- 身体构造:可伸缩利爪、消音肉垫、柔软脊椎——能钻过与头部等宽的缝隙、跳到自身高度 5 倍以上
- 行为语言:蹭人是在做气味标记、呼噜声的多重含义、尾巴与耳朵的姿态语言、"踩奶"源于幼年记忆
- 饮食与禁忌:猫是纯肉食动物,必须从肉类获取牛磺酸;另做一张醒目的"有毒危险清单"卡片:巧克力、洋葱大蒜、百合花、木糖醇等

## 4. 品种图鉴区(网站核心)
- 品种数据全部定义为 JS 数组对象,页面卡片由 JS 渲染,便于后续增删
- 收录 12 个品种:英国短毛猫、美国短毛猫、布偶猫、缅因猫、波斯猫、暹罗猫、俄罗斯蓝猫、孟加拉豹猫、苏格兰折耳猫、斯芬克斯猫、挪威森林猫、中华田园猫
- 每个品种的字段:
  - 中文名、英文名、原产地、体重范围、平均寿命、毛发类型(长毛/短毛/无毛)
  - 3~4 个性格标签(如"温柔巨人""话痨""高冷")
  - 五维评分(1~5):亲人度 / 活泼度 / 掉毛量 / 饲养难度 / 话痨程度,卡片上用进度条或爪印图标可视化
  - 120~180 字的介绍:外形特征、性格、历史或趣闻
  - 1~2 条「饲养小贴士」
- 苏格兰折耳猫需客观说明软骨遗传病的健康风险与繁育争议
- 卡片布局:图片 + 名称 + 基础信息 + 性格标签 + 评分条 + 「查看详情」
- 点击卡片弹出 Modal:完整介绍、饲养贴士、放大版评分可视化(雷达图或加粗进度条均可)
- 筛选器:按毛发类型(全部/长毛/短毛/无毛)与适合人群(适合新手/活泼家庭/安静陪伴);无匹配时显示友好的空状态

## 5. 趣味冷知识区
横向排布 8~10 张一句话卡片,例如:猫每天睡 12~16 小时;猫的鼻纹如同人类指纹一样唯一;猫尝不出甜味;呼噜声频率(25~150Hz)据说有助于放松;英文中一群猫被称为 a clowder……(可自行补充)

## 6. 页脚
一行版权声明 + 一句「科学养猫,领养代替购买」的公益提示。

# 二、视觉设计
- 整体气质:温暖治愈、精致可爱,拒绝廉价花哨
- 配色:奶油白底 + 焦糖橙/暖棕主色 + 猫爪粉点缀,全站克制统一
- 卡片大圆角(16~24px)、柔和投影、充足留白、信息层级清晰
- 品种卡片 hover 轻微上浮、阴影加深;各区块进入视口时用 IntersectionObserver 做淡入上移动画
- 图标优先用内联 SVG(猫爪印、鱼骨、猫耳)或 emoji
- 品种图片用占位图服务:https://loremflickr.com/400/300/<品种英文关键词>?lock=<序号>,每个品种固定 lock 值;如服务不可用,降级为"品种主题色渐变 + 大号 emoji"占位
- 完整移动端适配:导航折叠、卡片网格自动降为单列

# 三、技术要求
- 输出一个完整可直接运行的 HTML 文件,CSS/JS 全部内嵌,双击即可在浏览器打开,不依赖任何构建工具、框架或外部 JS 库
- 代码分区清晰并有简要注释:品种数据数组、卡片渲染、筛选逻辑、Modal、滚动动画
- 使用语义化标签(header/main/section/footer),无英文占位文案

# 四、输出方式
- 一次性输出完整代码;若因长度被截断,在我回复「继续」后从截断处无缝续写,不要重复已输出的部分
- 代码之后用 3~5 行说明:页面包含哪些区块、如何新增一个品种、后续可优化的方向
```

## 备选:React + TypeScript 版技术要求

如果希望 ChatGPT 直接产出可并入 TS 项目的代码,把上面提示词中「三、技术要求」整段替换为:

```text
# 三、技术要求
- 使用 React 18 + TypeScript + TailwindCSS,先给出完整项目目录结构,再逐个文件输出完整代码
- 组件按区块拆分独立文件:导航、Hero、科普区、品种卡片、筛选器、详情 Modal、冷知识、页脚
- 品种数据独立为 data 文件并附带 TypeScript 类型定义,五维评分等字段用注释说明含义
```
